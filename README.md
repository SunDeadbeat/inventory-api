# inventory-api

# Prerequisites
| environment | version | description | site |
|---|---|---|---|
| Git | 2.46.2 | Version control system | https://git-scm.com/ |
| Node.js | 20.17.0 | JavaScript runtime environment | https://nodejs.org/en/ |
| Docker | 27.5.1 | Platform as a service | https://www.docker.com/ |

# Install Dependencies
To install the necessary dependencies for the project, run the following command:

```sh
npm install
```

# Run in development mode
To run the project in development mode:

```sh
npm run dev
```

# Build
To build the project, run the following command:

```sh
npm run build
```

# Run
To start the application, run the following command:

```sh
node index.js
```
